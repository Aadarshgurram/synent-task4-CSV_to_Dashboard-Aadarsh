# synent-task4-CSV_to_Dashboard-Aadarsh

Netflix Interactive Dashboard
### 📌 Project Overview
This project is an interactive data dashboard built using Streamlit and the Netflix Titles Dataset.
The dashboard allows users to upload a CSV dataset, explore Netflix content, apply filters, and visualize trends dynamically.
The main objective of this project is to analyze Netflix content patterns and present insights through interactive visualizations.

### 🎯 Objective
Build an interactive dashboard using Streamlit
Upload and analyze CSV datasets dynamically
Display charts and visual insights
Identify trends and patterns in Netflix content

### 🛠️ Technologies Used
Python
Streamlit
Pandas
Matplotlib
Seaborn

### 📂 Dataset
Dataset Used: Netflix Titles Dataset
Dataset contains:
Movies and TV Shows
Release year
Country
Ratings
Duration
Date added
Genre information



### 🚀 Features
✅ CSV Upload
Users can upload the Netflix dataset directly through the dashboard.
✅ Interactive Filters
Dashboard supports filtering by:
Content Type (Movie / TV Show)
Country
✅ Dynamic Visualizations
The dashboard automatically updates charts based on selected filters.
Visualizations included:
Movies vs TV Shows
Content growth over time
Top content-producing countries
Movie duration distribution
✅ KPI Metrics
Dashboard displays:
Total Titles
Total Movies
Total TV Shows


### 📊 Key Insights
Example Insights
Netflix content increased rapidly after 2016.
Movies dominate the platform compared to TV Shows.
USA contributes the highest amount of Netflix content.
Most movie durations fall between 80–120 minutes.

### ⚙️ How to Run the Project
1. Install Required Libraries
pip install streamlit pandas matplotlib seaborn
2. Run the Streamlit App
streamlit run app.py
